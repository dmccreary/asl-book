# ASL Grammar and Expression

## Summary

Explores grammatical structures like role shifts, classifiers, agreement verbs, and non-manual signals (facial grammar). After completing this chapter, students will be able to recognize, understand, and apply these concepts in visual communication contexts.

## Concepts Covered

This chapter covers the following 20 concepts from the learning graph:

* Classifier
* Role Shift
* Time Marker
* Subject-Verb-Object
* Depicting Verb
* Spatial Reference
* Agreement Verb
* Rhetorical Question
* Conditional Statement
* Listing
* Non-Manual Signal
* Eyebrow Raise
* Eyebrow Furrow
* Head Nod
* Head Shake
* Eye Gaze
* Mouth Morpheme
* Body Lean
* Question Face
* Statement Face
